# AI Work Recipes

> **AIに詳しくならなくても、AIで仕事は楽にできる。**

AI Work Recipes は、AIの専門知識や最新モデルを前提にせず、日々の仕事を終わらせるための実践的な手順を「レシピ」として共有するプロジェクトです。

単なるプロンプト集ではありません。各Recipeに、利用手順、プロンプト、設計理由、最低限確認したモデル、限界、評価・テスト結果を含めます。一発回答に頼らず、必要に応じて複数の小さなステップと人間の確認を組み合わせます。

## 対象

- 組織や環境の制約でレガシーモデルを使っている人
- AIをこれから使い始める人
- AIそのものを深く学ぶ時間はないが、仕事を少し楽にしたい実務者

## 最初のRecipe

文字起こしから議事録を作るRecipeを、次の3ステップで設計します。

1. **抽出**：文字起こしから事実・決定事項・アクション候補・不明点を拾う
2. **判定・構造化**：情報を分類し、確認が必要な箇所を明示する
3. **編集・セルフチェック**：人間が必要箇所を確認し、読みやすい議事録に仕上げる

## 地域コミュニティとの循環

地域の困りごとを起点に、解決方法を設計し、Recipe化して実際に検証し、改善したものを公開します。コミュニティで使われた結果を次の版へ反映し、個別のノウハウを誰でも再利用できる形に育てます。

```text
困りごと → 解決方法の設計 → Recipe化 → 実地検証 → 改善・公開
```

## 状態

現在は初期設計段階です。Recipeの完成度は、`Draft`、`Tested`、`Community-tested`、`Stable` の状態で管理します。

詳しい方針は [docs/](docs/) を、Recipeの作成方法は [recipes/template.md](recipes/template.md) を参照してください。
