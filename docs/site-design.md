# サイトデザイン

Webサイト（利用者向け）の見せ方の基準。モック [mock/site-mock.html](mock/site-mock.html) で確認した内容をまとめる。実装は [../site/](../site/) にある。モックのプロンプトは作成時点の写しであり、正本は各Recipeの `prompts/` にある。

## 方針

- **先進的だが、AIに不慣れな人を緊張させない**。整った余白、等幅フォントのラベル、細いグリッドで先進的な印象を出し、色数は絞る
- 紫から青のグラデーション、黒地にネオン色のような、よくある「AIっぽい」見た目は使わない
- 初めての人はRecipeページを上から読めば使え、慣れた人はメニューから直接プロンプトをコピーできるようにする

## レイアウト

```text
┌──────────────────────────────────────────────┐
│ ヘッダ（スクロールしても上部に固定）           │
├──────────┬───────────────────────────────────┤
│ 左メニュー │ 本文（最大幅 760px の1カラム）       │
│ （開閉式） │                                   │
└──────────┴───────────────────────────────────┘
```

- **PC（幅900px以上）**：左メニューを常に表示する。ヘッダのボタンで折りたたむことができ、開閉の状態は閲覧者のブラウザに保存する
- **スマートフォン（幅900px未満）**：左メニューは、ヘッダのボタンで開く引き出し型にする。背景を暗くし、外側を押すと閉じる
- ヘッダは常に上部に固定する

### 左メニューの構成

1. レシピの検索
2. はじめての方へ（`guides/start.md`）／すべてのレシピ
3. 業務から探す：`categories.yml` の順にカテゴリを並べ、開閉式にする。各Recipeの下に、プロンプトごとに「STEP N をコピー」ボタン（N はプロンプトを置いたSTEPの番号）と文字数を置く。ステップの数とプロンプトの数はRecipeによって違う。準備中のRecipeは「SOON」と表示する
4. 困ったとき：長すぎて送れないとき（`guides/too-long.md`）、入力してはいけない情報
5. このサイトについて：最低動作モデルとは、ご意見・レシピの要望（フォーム）、技術者の方へ（GitHub）

## Recipeページの構成

上から次の順に置く。

1. カテゴリ、タイトル、一文の説明
2. カード（作業時間・難易度・操作数・最低動作モデル）と、用意するもの
3. 使う前に（入力してはいけない情報）
4. 使い方：STEP 1〜3 を縦のラインでつなぐ。STEP 2 は点線の番号で「必要なときだけ」と示す。プロンプトは折りたたんだパネルで表示し、「全文を表示」で展開する
5. 長すぎて送れないとき（折りたたみ。分割送信の定型文にもコピーボタン）
6. 最後に確認すること（チェックリストと進み具合のバー）
7. なぜこのプロンプトでうまくいくの？（折りたたみ）
8. 版と状態、技術者向けのGitHubへのリンク（目立たない形）

## 色

色は役割で使い分ける。ライトモードとダークモードの両方を用意する。

| 役割 | 色 | 使う場所 |
|---|---|---|
| アクセント | 青 | リンク、コピーボタン、ステップ番号、選択中のメニュー、難易度の★ |
| 完了・確認済み | 緑 | コピーした後のボタン、チェックリスト、進み具合のバー、「確認済み」の状態表示 |
| 中立 | グレー | 「未検証」「目標・未実測」などの状態表示、「使う前に」の欄の背景 |

- 緑は「完了・確認済み」の意味だけに使う。「未検証」を緑にすると確認済みに見えるため、状態表示は確認済みになるまでグレーの枠線にする
- 黄色やオレンジの警告色は使わない。「使う前に」は、目立たせすぎず、落ち着いたグレーの背景と細い枠線で示す

## 部品

- **プロンプトのパネル**：ライトモードでは明るいパネル、ダークモードでは暗いパネルにする。上部のバーにファイル名と文字数（`prompts/` から計算）を出し、等幅フォントで表示する
- **コピーボタン**：背景を塗らず、枠線と文字に色を付ける。普段は青、コピーした後は緑にして、約2秒で元に戻す。クリップボードが使えない環境では、全文を選択して「Ctrl+C でコピーしてください」と案内する
- **メニューのコピーボタン**：普段はグレーの枠。コピーした後は緑にする

## 文字

| 役割 | フォント |
|---|---|
| 本文・見出し | IBM Plex Sans JP |
| ラベル・プロンプト（英数字） | IBM Plex Mono |
| プロンプト（日本語） | BIZ UDGothic |

モックではGoogle Fontsから読み込んでいるが、実装では外部に頼らないため（[distribution.md](distribution.md) の「利用者のネットワーク環境」）、フォントファイルをサイトに含めて配信する（`@fontsource` のパッケージを使い、文字種ごとに分割されたファイルを必要な分だけ読み込む）。いずれもオープンなライセンス（SIL Open Font License）で配布されている。
