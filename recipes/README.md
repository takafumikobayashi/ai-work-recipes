# Recipes

このディレクトリには、特定の仕事を終わらせるための実践的な手順を置きます。

## 読み方

各Recipeは、次の順で読むと使いやすくなっています。

1. 目的と対象を確認する
2. 入力してよい情報・いけない情報を確認する
3. 手順を上から順に試す
4. 人間の確認点で止まり、出力を元資料と照合する
5. 評価結果と限界を確認してから実務に使う

## 状態

- `Draft`：設計案
- `Tested`：テスト結果を記録済み
- `Community-tested`：実際の利用者・現場で検証済み
- `Stable`：既知の制約が整理され、定期見直し中

状態は品質保証の代わりではありません。特に外部公開、重要な判断、機密情報の扱いでは、利用者と組織の確認を優先してください。

## 新しいRecipeを作る

1. [template.md](template.md) を複製する
2. [docs/recipe-spec.md](../docs/recipe-spec.md) の必須項目を埋める
3. 小さなテストセットで確認する
4. 結果・制約・改訂履歴を記録する
5. レビュー後に状態を更新する
