今のゲームで起きている不具合を調べ、原因を直してください。

# 起きていること

【何をしたとき、どうなるか。本当はどうなってほしいか】
（例：再スタートを押すと、残り時間が2倍の速さで減る。本当は1秒に1ずつ減ってほしい）


# 今のゲーム

同じ会話の場合は、直前に出したHTMLを使ってください。
別の会話で使う場合や、自分で書き換えた場合は、下の欄にHTMLの全文を貼ってください。

【今のHTML（同じ会話なら、このままで構いません）】


# 進め方

1. まず、原因を、ゲームを作ったことがない人にも分かる言葉で説明してください。
2. 原因に関係する部分だけを、最小限に直してください。


# 条件

- ほかの動作や見た目を変えない
- 新しい機能を加えない
- 原因がはっきりしない場合は、推測で大きく書き換えず、
  原因の候補と、確かめるために私がする操作を書いてください。


# 出力

1. 原因の説明
2. 修正した部分の説明（3行程度）
3. 修正後のHTMLの全文（1つのコードブロック。省略しない）
4. 確認する操作を3つ（直した不具合と、前からある機能の両方）
