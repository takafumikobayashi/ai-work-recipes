ここまでに作った「サイトの設計書」と、その後に私が伝えた変更に沿って、
ブラウザーで直接開ける1ページのWebサイトを作成してください。

別の会話で使う場合は、下の欄に設計書を貼ってください。

【サイトの設計書（同じ会話なら、このままで構いません）】


# ファイルの分け方

次のどちらかで作成してください。（使わない方を消してください）

A：HTMLファイル1つ（index.html）にまとめる
B：index.html、styles.css、script.js の3つに分ける


# 基本方針

- HTML、CSS、JavaScriptだけで作る
- React、Vue、Next.js、Astro などのフレームワークは使わない
- ビルドやパッケージのインストールを不要にする
- 外部のライブラリ、CDN、Webフォント、アクセス解析のコードを読み込まない
- 文字は、端末に入っているフォントを使う
- パソコン、タブレット、スマートフォンに対応する
- 設計書の文章・固有名詞・日時・金額・連絡先は、変えずにそのまま使う
- 設計書にない事実を作らない
- 「【仮】」が付いた文章は、ページの上でも「【仮】」を付けたまま表示する
- 「要確認」のリンク先は `#` にし、`<!-- 要確認：リンク先 -->` のコメントを付ける


# デザインの決まり

設計書の「デザインの型」の考え方に沿って、見た目を整えてください。

- A（デジタル庁デザインシステム）：落ち着いた配色、はっきりした見出し、ゆとりのある行間、
  装飾を控えて情報を読みやすく並べる
- B（Material Design 3）：基調色から作った調和のある配色、角丸のカード、
  控えめな影、押しやすく分かりやすいボタン

どちらの場合も、考え方を参考にするだけにしてください。
- 外部のCSSやコンポーネントを読み込まず、自分でCSSを書く
- デジタル庁・政府・Googleのロゴやマーク、名前を、ページに表示しない
- 行政や企業の公式のサイトと誤解される見た目や文言にしない

あわせて、次の共通の決まりを守ってください。

- 余白は 8px の倍数（8・16・24・32・48・64px）から選ぶ
- 文字の大きさは、本文 16px 以上。見出しは3段階程度に決め、本文との差をはっきりさせる
- 本文の行間は 1.7 前後。1行は全角40字前後までにする
- 色は、基調色1つ、アクセントの色1つ、グレーの濃淡だけにする
- 文字と背景の明るさの差（コントラスト比）は 4.5:1 以上にする
- 角丸・影・線の太さは、ページ全体で同じ値を使う
- ボタンやリンクは、指で押しやすい大きさ（高さ 44px 以上）にする
- 画像の枠は、縦横の比率を揃える
- 色・余白・文字の大きさは、CSS変数にまとめる


# 申込・問い合わせ

- 送信の仕組みが必要な入力フォームは作らない（このサイトだけでは送信できないため）
- 申込や問い合わせは、設計書にあるフォームのURL、メールアドレス、電話番号へのリンクにする


# 画像

- 画像ファイルは使わず、画像を置く場所には、差し替え用の枠を作る
- 枠には、どんな画像を置くか（設計書の内容）と、差し替え方法を、コメントで書く
- 内容を伝える画像には内容に合った alt 属性を、飾りの画像には空の alt 属性を付ける


# スクロールの動き

- 各セクションが画面に入ったとき、下から少し上がりながら、約0.6秒でふわっと表示する
  （始め：opacity 0、translateY(24px)　→　表示：opacity 1、translateY(0)）
- 同じセクションの中のカードは、80〜120ミリ秒ずつ遅らせて表示する
- 一度表示したものは、上下にスクロールしても繰り返さない
- JavaScriptが動かない環境でも、内容が見えなくならないようにする
- `prefers-reduced-motion: reduce` の場合は、動きをなくす
- メニューのリンクは、該当するセクションへなめらかに移動する
- ボタンは、マウスを重ねたときに色または影を控えめに変える
- 大きく動く背景（パララックス）、点滅、画面全体を覆う動きは使わない
- 大事な情報を、動きだけで伝えない


# アクセシビリティ

- 見出しの階層を正しくする（h1 は1つ）
- header、nav、main、section、footer など、役割の分かるタグを使う
- キーボードだけで操作でき、フォーカスしている場所が分かるようにする
- 文字と背景の色の差を十分にとる


# 技術要件

- CSS変数で、色と余白を管理する
- class名は、役割が分かる名前にする
- 画面の幅が320px程度でも、横にスクロールしないようにする
- title、meta description、viewport を設定する
- OGP（SNSで共有したときの表示）の基本の設定を入れる。
  サイトのURLと共有用の画像のURLが決まっていない場合は、値を「要確認」にし、コメントを付ける
- コードには、変更しやすい場所にだけ、日本語のコメントを付ける


# 出力

最初に、作り方の方針を5行以内で説明してください。
その後、次の順番で出力してください。

1. コード（Aの場合は index.html、Bの場合は index.html・styles.css・script.js）
   ファイルごとに1つのコードブロックにし、「…省略…」のように省略しない
2. 作った機能の一覧
3. 変更しやすい場所（色、文章、画像の枠など）
4. ブラウザーでの確認方法
5. 【仮】の文章、「要確認」の項目、差し替えが必要な画像の一覧
