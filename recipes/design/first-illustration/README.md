# 設計と検証：まずは1枚、イラストを作ってみる

技術者・改善に参加したい人向けの文書。プロンプトがなぜこの形になっているのか、苦手なケース、評価方法を説明する。

利用者向けの使い方はWebサイトに表示する。その素材は [page.md](page.md)（カード・使い方・注意）と [prompts/](prompts/)（コピー用プロンプト）にある。

## 1. 設計目標

> **画像生成を使ったことがない人が、何も書き換えずにプロンプトを貼るだけで、見せたくなる1枚のイラストを作り、一言の頼み方で絵を変える体験ができること。**

[用途に合わせたイラストを作る](../illustration/) の超初心者版。設計書を作る前の「まず1枚できた」という体験と、「一言で変えられる」というアレンジの入口を目的にする。成果物を仕事に使うことより、画像生成の手応えをつかむことを優先する。

## 2. この仕事の分解

利用者がすることは、貼ることだけにした。そのために、[illustration](../illustration/) の設計書でAIが下書きする項目（用途、場所、季節、時間帯、必ず入れるもの、構図、画風、入れないもの）を、あらかじめプロンプトの中で決めてある。

```text
STEP 1　固定のプロンプトを貼る → イラスト1枚 ＋ 一言の頼み方の例3つ
    ↓
STEP 2　（必要なら）一言で変える
```

### 題材の選び方

| 条件 | 「川沿いの町の秋の夕方」で満たしていること |
|---|---|
| だれが見ても好ましい | 季節の風景、親子、夕焼け、窓の明かり |
| 画像生成で崩れにくい | 人物は小さく2人だけ。手や顔の細部が目立たない構図 |
| 文字が入りにくい | 看板や店先など、文字が描かれやすいものを入れない |
| アレンジしやすい | 季節・時間帯・人物・画風を、一言で変えられる |
| 地域を限定しない | 特定の場所ではなく、どこにでもありそうな日本の町 |

### 一言の頼み方の例を出させる理由

画像のあとに「一言の頼み方」の例を3つ出させる。利用者が「次に何を頼めばよいか」で止まらないようにし、アレンジの言い方の型（変えたいところだけを、短く頼む）を体験から覚えられるようにするためである。

## 3. 判断基準

成果物の正しさの基準はない。描くもの6つと雰囲気が出ていれば成功とする。

## 7. 限界と注意点

- 画像生成ができないAIでは使えない
- 一言のアレンジを重ねると、最初の雰囲気から離れたり、文字のような模様が出たりすることがある
- 仕事で使う絵（チラシ、Webサイト）には、用途に合わせて余白などを決められる [illustration](../illustration/) を使う
