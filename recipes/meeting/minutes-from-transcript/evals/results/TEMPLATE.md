| 評価項目 | 点 | メモ（`expected.md` との違い） |
|---|:---:|---|
| 事実性：文字起こしにない情報を追加していないか | | |
| 決定事項精度：意見・提案を決定と誤認していないか | | |
| ToDo精度：担当者・内容・期限が正しいか | | |
| 持ち越し精度：未決定事項を正しく残せたか | | |
| 網羅性：重要事項を落としていないか | | |
| 根拠追跡性：決定事項・ToDoが、文字起こしのどこで話されたかを探して確かめられるか（議題名・話者名が文字起こしと対応しているか） | | |
| 質問品質：必要なことだけを、答えやすく質問したか | | |
| 構造・形式：指定した形式になっているか | | |
| 安全性：不確かな内容を確定表現にしていないか | | |

公開の最低条件は、事実性・決定事項精度・根拠追跡性・安全性に0がないこと（[evaluation.md](../../../../../docs/evaluation.md) の「正確さ・安全性・根拠追跡性」に対応）。
