これから議事録を作成します。
この段階では完成版の議事録は作らず、以下の文字起こしから
「議事録を作成するために必要な情報」を正確に抽出・整理してください。

# 最重要原則

文字起こしに記録されている内容を事実の根拠としてください。

文字起こしにない事実を推測して追加しないでください。
特に、決定事項・担当者・期限・数値・固有名詞を推測で確定してはいけません。

「発言されたこと」と「会議として決まったこと」は別です。
意見や提案があっただけの場合は、決定事項として扱わないでください。


# 処理手順

必ず次の順番で処理してください。

## 1. 抽出

文字起こし全体を確認し、議事録に必要な情報を抽出してください。

以下は整理・除外して構いません。

- 「えー」「あのー」などのフィラー
- 意味のない相づち
- 同じ内容の重複
- 明らかな言い直し
- 議事録に不要な雑談

ただし、発言の意味や結論を変えてはいけません。


## 2. 判定

抽出した内容を、次の基準で判定してください。

【議論・意見】
会議中に出された説明、意見、質問、提案など。

【結論】
その議題について、最終的にどのような状態になったか。
途中で結論が変わった場合は、最後の結論を採用してください。

【決定事項】
会議として明確に合意・確定したこと。
単なる意見、提案、検討案は含めません。

【ToDo】
会議後に誰かが実行・確認・対応すること。
「担当者」「内容」「期限」をそれぞれ確認してください。

【持ち越し事項】
結論が出ていないこと、継続検討となったこと、
次回以降に判断・確認すること。


## 3. 整理

以下の形式で必ず整理してください。

# 会議情報
- 会議名：
- 日時：
- 参加者：

文字起こしから確認できない項目は「不明」としてください。

# 議題と議論

## 議題1：〇〇
- 主な議論：
- 主な意見・提案：
- 結論：

## 議題2：〇〇
- 主な議論：
- 主な意見・提案：
- 結論：

議題数に応じて増減してください。

# ToDo

| 担当者 | 内容 | 期限 |
|---|---|---|
| | | |

不明な項目は「不明」としてください。
推測で補完しないでください。

# 持ち越し事項

# その他の重要事項

## 4. 確認

最後に、上記の整理結果を確認してください。

正確な議事録を作るうえで重要な情報が不足・曖昧で、
利用者に確認することで議事録の正確性が大きく向上する場合だけ、
質問してください。

質問する必要がない細かな情報については質問しないでください。

特に確認対象となり得るのは以下です。

- 決定したのか、単なる提案なのか判断できない
- 重要なToDoの担当者が分からない
- 重要なToDoの期限が分からない
- 固有名詞の誤変換が疑われ、意味が変わる可能性がある
- 誰の発言かによって意味が大きく変わる

質問が必要な場合は、

# 確認したいこと

1. ○○について、〜でしょうか？
2. ○○について、〜でしょうか？

のように、短く回答できる形で質問してください。
候補が絞れる場合は、「A：〜　B：〜」のように選択肢を添えてください。

重要な確認事項がない場合は、

# 確認したいこと
重要な確認事項はありません。

としてください。


# 禁止事項

以下は行わないでください。

- 文字起こしにない情報の創作
- 文脈だけを根拠とした担当者・期限の確定
- 提案を決定事項に変更すること
- 未決定事項を決定済みとして扱うこと
- 発言者の意図を変えること
- 不明な固有名詞を勝手に修正すること
- 議事録の見栄えを良くするための事実の補完
- 不要な質問を大量にすること

この段階では完成版の議事録を作成しないでください。
