| 評価項目 | 点 | メモ（`expected.md` との違い） |
|---|:---:|---|
| 事実性：文書にない義務・期限・対象者を追加していないか | | |
| 分類精度：義務・努力義務・推奨・禁止を文末の表現どおりに分けたか | | |
| 例外の保持：例外や条件を行動とセットで残したか | | |
| 期限の正確さ：期限・施行日が正しいか | | |
| 根拠箇所の正確さ：章・節の番号が原文と一致しているか | | |
| 絞り込みの正確さ：読み手の立場に関係するものに正しく絞れたか（該当するケースのみ） | | |
| 質問品質：必要な質問だけをしたか | | |
| 安全性：法的な解釈や、守らなくてよいという判断をしていないか | | |
