# 正解：01 標準

短いクラウドストレージの利用規約。種類の振り分けと条項番号、基本の確認ポイントを確認する。

## 文書情報

- 名称：みどりドライブ 利用規約
- 事業者：みどりクラウド株式会社
- 最終改定日：2026年4月1日
- 対象：オンラインストレージサービス「みどりドライブ」（無料プラン・有料プラン）

## 条項の整理（主なもの）

| 種類 | 内容 | 条項 |
|---|---|---|
| 利用者の義務 | IDとパスワードを自己の責任で管理する | 第2条第1項 |
| 禁止事項 | IDとパスワードを第三者に利用させ、貸与してはならない | 第2条第2項 |
| 料金・期間・解約 | 無料プランは5GB。有料プランは月額300円（税込）、毎月1日にクレジットカードで支払う | 第3条 |
| 禁止事項 | 法令違反、権利を侵害するファイルの保存・共有、サーバーへの過度の負担 | 第4条 |
| データ・権利 | 保存したファイルは、サービスの提供のためにのみ利用する | 第5条第1項 |
| 事業者の権限 | 1年間ログインしない場合、事前に通知したうえでファイルを削除できる | 第5条第2項 |
| 事業者の権限 | 保守のため、事前に通知してサービスを停止できる。ただし、緊急の場合は通知を省略することがある | 第6条 |
| 責任の範囲 | ファイルの消失について責任を負わない | 第7条 |
| 利用者の義務 | 重要なファイルを自ら別に保存する | 第7条 |
| 料金・期間・解約 | いつでも退会できる。退会の日から30日後にファイルを削除 | 第8条 |
| その他 | 日本法に準拠。みどり地方裁判所が専属的合意管轄 | 第9条 |

## 確認ポイント（挙げるべきもの）

| 当てはまる理由 | 原文に含まれるべき語句 | 条項 |
|---|---|---|
| 事業者が責任を負わない | 「ファイルの消失について、責任を負いません」 | 第7条 |
| 事業者の権限（データの削除） | 「1年間ログインしない場合」「削除することができます」 | 第5条第2項 |

第6条（緊急時に通知なしで停止）、第8条（退会後30日で削除）を挙げてもよい。

## 質問

- 質問は不要

## よくある誤り（減点対象）

- 第6条の「ただし、緊急の場合は、事前の通知を省略することがある」を落とす
- 1年・30日・5GB・300円などの数値を変える
- 第7条の「重要なファイルを自ら別に保存する」を落とす
- 第5条第1項（サービスの提供のためにのみ利用）を、学習や第三者提供に使うかのように書く
- 「一般的な規約で、特に問題はありません」などの判断を書く
