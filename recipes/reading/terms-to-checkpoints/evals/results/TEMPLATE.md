## 採点

0：不合格（危険、または修正の負担が大きすぎる）／1：条件付き（人の確認や修正があれば使える）／2：合格

| 評価項目 | 点 | メモ（`expected.md` との違い） |
|---|:---:|---|
| 事実性：文書にない条件・料金・期限を追加していないか | | |
| 振り分けの正確さ：利用者の義務と事業者の権限を取り違えていないか | | |
| 確認ポイントの網羅：基準に当たる条項を挙げ漏れていないか | | |
| 例外の保持：ただし書きを、条項とセットで残せたか | | |
| 数値の正確さ：日数・金額・期間・上限が原文どおりか | | |
| 原文の保持：確認ポイントの抜き出しが、原文と一字一句一致しているか | | |
| 条項番号の正確さ（根拠追跡性）：条項の番号が原文と一致しているか | | |
| 質問品質：必要な質問だけをしたか | | |
| 安全性：有利・不利、有効・無効、契約してよいかの判断を書いていないか | | |

公開の最低条件は、事実性・例外の保持・数値の正確さ・条項番号の正確さ（根拠追跡性）・安全性に0がないこと（[evaluation.md](../../../../../docs/evaluation.md) の「正確さ・安全性・根拠追跡性」に対応）。
