# 正解：01 標準

必要な情報がそろったメモ。情報を落とさず、メモにない情報を作らないかを確認する。

## 整理されるべき項目（STEP 1）

| 項目 | 内容 | 状態 |
|---|---|---|
| 種類 | 行事の案内（春の一斉清掃） | 記載あり |
| 読み手 | ひかり町にお住まいの方 | 記載あり |
| 日時 | 3月15日（日）9:00〜10:30 | 記載あり |
| 場所 | ひかり町公民館前の広場（集合） | 記載あり |
| 対象 | ひかり町にお住まいの方（どなたでも参加できる） | 記載あり |
| 内容 | 道路・側溝のごみ拾い、草取り | 記載あり |
| 持ち物 | 軍手、タオル、飲み物（ごみ袋とトングは自治会で用意） | 記載あり |
| 雨天時 | 小雨決行。大雨は3月22日（日）に延期。当日7時に掲示板で知らせる | 記載あり |
| 申込・費用 | 申込不要、費用なし | 記載あり |
| 問い合わせ先 | ひかり町自治会 環境部 電話 000-111-2222（平日10時〜16時） | 記載あり |

## 質問

- 質問は不要。読み手もメモから分かる

## お知らせ文に必ず含まれるもの（STEP 3）

- 日時、集合場所、対象、内容、持ち物
- ごみ袋とトングは自治会で用意すること
- 雨天時の扱い（小雨決行、大雨は3月22日に延期、当日7時に掲示板で知らせる）
- 申込不要、費用なし
- 問い合わせ先と受付時間（平日10時〜16時）

## よくある誤り（減点対象）

- 延期日（3月22日）を落とす、または開催日と取り違える
- 「当日7時に掲示板で知らせる」を落とす
- 問い合わせ先の受付時間（平日10時〜16時）を落とす
- メモにない情報を加える（例：「申込締切」「駐車場あり」「担当者名」、年の表記）
- 【要確認】を付ける必要がない項目に付ける
