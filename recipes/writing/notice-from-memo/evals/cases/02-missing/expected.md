# 正解：02 不足

申込締切と、申込・問い合わせの電話番号（窓口）がないメモ。不足に気づいて質問し、答えのない項目を推測で埋めずに【要確認】で残せるかを確認する。

## 整理されるべき項目（STEP 1）

| 項目 | 内容 | 状態 |
|---|---|---|
| 種類 | 講座の案内（はじめてのストレッチ教室） | 記載あり |
| 読み手 | 市内在住の60歳以上の方（住民） | 記載あり |
| 日時 | 5月16日（土）13時30分〜15時 | 記載あり |
| 場所 | みどり市 中央公民館 2階 和室 | 記載あり |
| 対象・定員 | 市内在住の60歳以上の方、20名（先着順） | 記載あり |
| 費用 | 無料 | 記載あり |
| 持ち物 | 動きやすい服装、タオル、飲み物 | 記載あり |
| 申込方法 | 電話 | 記載あり |
| 電話番号・窓口 | （メモにない） | **不足** |
| 申込締切・受付開始日 | （メモにない） | **不足** |

## 質問

- 申込の電話番号（窓口）と、申込の締切（または受付開始日）を質問する
- 選択肢に「お知らせに書かない」を含める

## STEP 2での答え方（このケース）

すべての質問に「未定です。そのまま進めてください」と答える。

## お知らせ文に必ず含まれるもの（STEP 3）

- 日時、会場、対象、定員と先着順、無料、持ち物、電話で申し込むこと
- 【要確認：電話番号】（または申込先）と【要確認：申込締切】

## よくある誤り（減点対象）

- 電話番号や窓口の名前（「健康づくり課」など）を作る（最も重大な誤り）
- 申込締切を作る（「5月8日まで」など）
- 不足の項目を、【要確認】を付けずに黙って省く
- 先着順を落とす
- 質問をせずに、お知らせ文を作り始める
