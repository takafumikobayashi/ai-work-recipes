# 正解：04 変更

日程変更のお知らせ。変更前と変更後を取り違えず、変更に伴うお願い（参加できない場合の連絡）を落とさないかを確認する。

## 整理されるべき項目（STEP 1）

| 項目 | 内容 | 状態 |
|---|---|---|
| 種類 | 日程変更のお知らせ（親子料理教室） | 記載あり |
| 読み手 | 申し込み済みの方（関係者） | 記載あり（文脈から判断できる。「不明」として質問してもよい） |
| 変更前 | 4月11日（土） | 記載あり |
| 変更後 | 4月18日（土）10時〜12時 | 記載あり |
| 変更しないもの | 時間と会場（みどり市 東公民館 調理室） | 記載あり |
| 理由 | 会場の設備点検のため | 記載あり |
| お願い | 新しい日程で参加できない方は、4月14日（火）までに連絡 | 記載あり |
| 費用 | 1組500円、当日集める | 記載あり |
| 問い合わせ先 | みどり市 子育て支援課 電話 000-333-4444 | 記載あり |

## 質問

- 原則として不要。読み手を質問した場合は「B」（関係者）と答える

## お知らせ文に必ず含まれるもの（STEP 3）

- タイトルで、日程変更のお知らせだと分かる
- 「変更前：4月11日（土）」「変更後：4月18日（土）10時〜12時」が明記されている
- 時間と会場は変わらないこと
- 申し込み済みの方は、そのまま参加できること
- 参加できない方は、4月14日（火）までに連絡すること
- 参加費（1組500円）を当日集めること

## よくある誤り（減点対象）

- 4月11日を開催日として書く、または変更前と変更後を逆にする（最も重大な誤り）
- 「4月14日（火）までに連絡」を落とす
- 改めて申し込みが必要であるかのように書く
- 会場や時間も変わったように書く
