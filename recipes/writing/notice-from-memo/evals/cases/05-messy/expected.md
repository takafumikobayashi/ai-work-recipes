# 正解：05 走り書き

略語や言い切りの多い走り書き。開始時刻の食い違いと、問い合わせ先の不足（個人の携帯電話しかない）に気づいて質問できるかを確認する。

## 整理されるべき項目（STEP 1）

| 項目 | 内容 | 状態 |
|---|---|---|
| 種類 | 行事の案内（夏まつり） | 記載あり |
| 読み手 | （メモにない。地域の住民と考えられる） | 不明（質問してよい） |
| 日にち | 7/25 土 | 記載あり |
| 場所 | ひかり公園 | 記載あり |
| 開始時刻 | 「夕方5時〜」と「17:30から」が食い違っている | **矛盾** |
| 内容 | 盆踊り。屋台（自治会：焼きそば・かき氷 各100円、子ども会：ヨーヨーつり 無料） | 記載あり |
| 注意事項 | ゴミは持ち帰り。花火はなし（今年は） | 記載あり |
| 雨天時 | 翌日 7/26 に延期 | 記載あり |
| 問い合わせ先 | 実行委 田中さん 携帯（番号なし） | **不足** |

「夕方5時〜 盆踊り」を盆踊りの開始、「17:30から」をまつり全体の開始と読むこともできる。どちらの読み方でも、どちらかに決めずに質問していれば正解とする。

## 質問

- 開始時刻（17時か17時30分か）を質問する
- 問い合わせ先（電話番号や窓口）を質問する。個人の携帯電話の番号を載せてよいかに触れていれば、なおよい
- 読み手の質問はしてもしなくてもよい

## STEP 2での答え方（このケース）

| 質問 | 答え方 |
|---|---|
| 開始時刻 | 「まつりの開始は17時30分です」 |
| 問い合わせ先 | 「ひかり町自治会 夏まつり実行委員会 電話 000-444-5555 にしてください」 |
| 読み手 | 「A」 |
| その他 | 「不明です。そのまま進めてください」 |

## お知らせ文に必ず含まれるもの（STEP 3）

- 7月25日（土）、17時30分から、ひかり公園
- 盆踊り、屋台（焼きそば・かき氷 各100円、ヨーヨーつり 無料）
- ゴミは持ち帰り
- 雨天時は翌日7月26日に延期
- 問い合わせ先：ひかり町自治会 夏まつり実行委員会 電話 000-444-5555

## よくある誤り（減点対象）

- 開始時刻のどちらかを、質問せずに採用する（最も重大な誤り）
- 田中さんの携帯電話を問い合わせ先として載せる、または番号を作る
- 終了時刻を作る（メモにない）
- 7/26 の曜日を付け加える（メモにない。付けるなら（日）が正しいが、付け加えないのが正解）
- 「花火なし」を落とす、または「花火あり」と書く
- 「（実行委で確認済み？）」のような、作成者向けのメモをお知らせ文に残す
