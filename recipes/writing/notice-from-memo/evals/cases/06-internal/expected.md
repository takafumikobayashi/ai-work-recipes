# 正解：06 職員向け

社内（職員）向けのお知らせ。住民向けとは違う、職員向けの言葉づかいになるか、期限と代わりの手順を落とさないかを確認する。

## 整理されるべき項目（STEP 1）

| 項目 | 内容 | 状態 |
|---|---|---|
| 種類 | システム停止のお知らせ | 記載あり |
| 読み手 | 全職員（社内・職員） | 記載あり |
| 停止日時 | 5月23日（土）8:00〜5月24日（日）18:00 | 記載あり |
| 理由 | サーバー機器の入れ替え | 記載あり |
| 影響 | 出退勤の打刻、休暇の申請、旅費の申請ができない | 記載あり |
| 停止前にすること | 休暇の申請は、5月22日（金）17時までに済ませる | 記載あり |
| 停止後にすること | 打刻できなかった分は、5月25日（月）以降に「打刻修正」で入力 | 記載あり |
| 停止中の代わりの手順 | 急ぎの申請は、紙の様式（庶務システム停止時用）で所属長に提出 | 記載あり |
| 問い合わせ先 | 総務課 情報担当 内線 1234 | 記載あり |

## 質問

- 質問は不要。読み手はメモから分かる

## お知らせ文に必ず含まれるもの（STEP 3）

- 停止日時（開始と終了の両方）
- できなくなること（打刻、休暇の申請、旅費の申請）
- 休暇の申請の期限：5月22日（金）17時まで
- 打刻の修正方法：5月25日（月）以降に「打刻修正」で入力
- 急ぎの申請の代わりの手順：紙の様式で所属長に提出
- 問い合わせ先：総務課 情報担当 内線 1234

## 言葉づかいの基準

- 職員向けの、簡潔で丁寧な文体（「〜をお願いします」「〜してください」）
- 住民向けのような、長いあいさつや、くだけすぎた表現は不要
- 「打刻修正」など、職員が画面で見る名前は言い換えない

## よくある誤り（減点対象）

- 休暇の申請の期限（5月22日（金）17時）を落とす（最も重大な誤り）
- 停止の終了日時を落とす、または開始と取り違える
- 旅費の申請が止まることを落とす
- 「打刻修正」を別の言葉に言い換える
- 停止の理由を詳しく作り足す（メモは「サーバー機器の入れ替え」だけ）
