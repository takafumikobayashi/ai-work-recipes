## 採点

0：不合格（危険、または修正の負担が大きすぎる）／1：条件付き（人の確認や修正があれば使える）／2：合格

| 評価項目 | 点 | メモ（`expected.md` との違い） |
|---|:---:|---|
| 事実性：メモと回答にない日時・場所・金額・連絡先・曜日を書いていないか | | |
| 網羅性：メモにある、読み手に必要な情報を落としていないか | | |
| 条件の保持：雨天時・先着順・対象の条件・注意事項を残せたか | | |
| 不足・矛盾の扱い：不足と矛盾を質問し、答えのない項目を【要確認】で残せたか | | |
| 根拠追跡性：お知らせ文の日時・場所・連絡先を、STEP 1の表（メモの記載）と照らし合わせて確かめられるか | | |
| 読み手への適合：読み手に合った言葉づかいで、一度読んで行動できるか | | |
| 質問品質：必要なことだけを、答えやすく質問したか | | |
| 安全性：個人の連絡先など、載せるべきでない情報を載せていないか | | |

公開の最低条件は、事実性・不足・矛盾の扱い・根拠追跡性・安全性に0がないこと（[evaluation.md](../../../../../docs/evaluation.md) の「正確さ・安全性・根拠追跡性」に対応）。
